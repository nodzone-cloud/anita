# Worker для настоящего AUTO RU / EN / FI

Этот Worker нужен только для режима **AUTO**, когда посетитель может говорить на русском, английском или финском независимо от языка страницы.

Почему он нужен: обычный браузерный `SpeechRecognition` принимает один `recognition.lang` на сессию. Он не гарантирует корректное автоматическое распознавание трёх языков одновременно. Поэтому AUTO записывает только короткую голосовую команду и отправляет её на серверную транскрипцию.

## Что сделать

1. Создай Cloudflare Worker.
2. Загрузи в него `openai-transcribe-worker.js`.
3. Добавь secret `OPENAI_API_KEY` через Cloudflare / Wrangler. **Никогда не вставляй API key в Tilda или GitHub JS.**
4. Разрешённые домены задаются в `ALLOWED_ORIGINS`. По умолчанию: `https://alexnode.fi,https://www.alexnode.fi`.
5. После публикации получишь адрес примерно вида:
   `https://alex-node-voice-transcribe.<account>.workers.dev/transcribe`
6. В `tilda/MAIN_T123_REPLACE_SCRIPT.html` вставь этот адрес в `transcribeEndpoint`.

Модель в Worker: `gpt-4o-mini-transcribe`. Язык специально НЕ задаётся — это позволяет транскрипции определить русский, английский или финский автоматически.

## Без Worker

Сайт всё равно работает через Web Speech API, но распознавание будет зависеть от выбранного языка голоса. Маршрутизация после распознавания уже понимает команды на всех трёх языках.
