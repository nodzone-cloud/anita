# Voice Website — Alex Node Voice

Готовый набор файлов для GitHub и Tilda.

## Что изменено

- Весь JavaScript вынесен из большого T123-кода в отдельные файлы.
- Команды маршрутизации понимают **русский, английский и финский независимо от языка интерфейса сайта**.
- Добавлены голосовые команды для переключения языка сайта.
- Добавлен режим **AUTO · RU / EN / FI**.
- Для настоящего автоматического распознавания трёх языков добавлен отдельный Cloudflare Worker.
- Если Worker не подключён, сайт использует браузерный Web Speech API как fallback.
- Исправлена карточка Alex Node Voice: в исходном коде было лишнее `"` в `href="https://alexnode.fi/smartwebsite""`.
- Команды Human Tech, цены, процесс, контакты, ANITA и языки находятся отдельно в `03-voice-routes.js`, поэтому их легко расширять.

## 1. Загрузка в GitHub

Загрузи всю папку **Voice Website** в свой репозиторий.

Публичный репозиторий проще всего подключить к Tilda через jsDelivr.

Пример ссылки:

```text
https://cdn.jsdelivr.net/gh/GITHUB_USER/REPOSITORY@main/Voice%20Website/js/05-voice-engine.js
```

В файле `tilda/MAIN_T123_REPLACE_SCRIPT.html` замени:

- `GITHUB_USER`
- `REPOSITORY`

на свои значения.

## 2. Что менять в текущем T123 сайта

Текущие HTML и CSS оставь такими, как они у тебя уже есть.

В самом низу твоего T123 сейчас находится большой блок:

```html
<script>
  const translations = ...
  ...
</script>
```

**Удаляешь только этот старый `<script>...</script>` полностью.**

На его место вставляешь содержимое:

`Tilda → MAIN_T123_REPLACE_SCRIPT.html`

После этого весь JS будет приходить из GitHub.

## 3. Карточка на главном сайте

Для карточки используй готовый файл:

`Tilda → CARD_T123.html`

Там уже исправлен `href`, а перевод карточки вынесен в `js/voice-card.js`.

## 4. Как работают три языка

### После распознавания

Маршрутизатор всегда проверяет **все три языка**. Поэтому если интерфейс страницы стоит на финском, но транскрипция получилась:

```text
Покажи цены
```

сайт всё равно перейдёт к разделу цен.

То же самое работает наоборот для английских и финских команд.

### Само распознавание речи

Есть два режима.

**Browser mode** — бесплатный Web Speech API. Быстрый, но браузер обычно использует один выбранный `recognition.lang` на сессию.

**AUTO · RU / EN / FI** — короткая голосовая команда записывается браузером, после паузы отправляется на серверную транскрипцию без жёстко заданного языка. Это и даёт настоящее автоматическое распознавание RU / EN / FI независимо от языка сайта.

Для AUTO смотри `worker/README_RU.md`.

## 5. Настройка AUTO

После публикации Worker вставь его адрес в:

```html
window.AN_VOICE_CONFIG = {
  transcribeEndpoint: "https://YOUR-WORKER.workers.dev/transcribe"
};
```

Это находится в `MAIN_T123_REPLACE_SCRIPT.html`.

API key должен храниться **только как secret в Worker**. Не вставляй его в Tilda, GitHub JS или HTML.

## 6. Проверка

После публикации Tilda:

1. Открой сайт по HTTPS.
2. Открой голосовую панель.
3. Разреши доступ к микрофону.
4. Для AUTO произнеси, например, «Покажи цены» на странице с финским интерфейсом.
5. Проверь команды из `TEST_COMMANDS.md`.

## Важное отличие от старого кода

В старом варианте было:

```js
recognition.lang = voiceLanguage.value;
```

То есть одна сессия распознавания была привязана к одному языку. Маршрутизатор мог содержать русские, финские и английские слова, но если сам браузер неправильно распознал речь из-за неверного `recognition.lang`, до маршрутизатора уже приходил неправильный текст.

В новой версии это разделено:

1. распознавание речи;
2. многоязычная транскрипция;
3. единый RU/EN/FI маршрутизатор;
4. действие на странице.
