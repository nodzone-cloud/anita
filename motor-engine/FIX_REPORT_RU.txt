MOTOR ENGINE — FIX REPORT (финальная версия)
============================================

1. Что восстановлено / исправлено в Voice Session
-------------------------------------------------
- Одна активация микрофона при первом входе (полноэкранный оверлей).
- Intro MP3 играет ровно один раз.
- После активации — только компактный зелёный индикатор (●).
- Старая большая панель «Нажмите микрофон…» больше НЕ появляется.
- SPA-навигация: content меняется без перезагрузки документа.
- SpeechRecognition не уничтожается при переходах.
- continuousVoice остаётся true на всём пути.
- Recognition останавливается перед play() MP3 и возобновляется только после audio.ended.
- Неизвестная речь молча игнорируется.
- Все 20 MP3 сохранены без изменений.

2. Пункт №1 — Цена + евро = подсветка карточки (приоритет)
----------------------------------------------------------
Если в речи есть сумма + евро/euro/€:
  «49 евро», «сорок девять евро», «49 euro»,
  «диагностика 49 евро», «сорок девять евро стоит диагностика»
→ сайт остаётся на (или переходит на) странице Цены
→ подсвечивается соответствующая карточка (price-49 / price-99 / price-120)
→ переход на подробности услуги НЕ выполняется.

Цена имеет абсолютный приоритет над названием услуги.

3. Пункт №2 — Диагностика / Service / Performance работают одинаково
--------------------------------------------------------------------
- «диагностика» / естественные варианты → подробности диагностики
- «service» / «сервис» / «техническое обслуживание» → подробности Service
- «performance» / «перформанс» → подробности Performance

Все три используют одну и ту же SPA-логику и не требуют повторной активации микрофона.

4. Пункт №3 — Динамическая страница подробностей
------------------------------------------------
Один шаблон service-detail.html + данные SERVICE_DETAILS:
- Диагностика → заголовок «Подробнее о диагностике» + своё содержание
- Service → «Подробнее о Service» + своё содержание
- Performance → «Подробнее о Performance» + своё содержание

Голос и клики используют одну систему.

5. Изменённые файлы
-------------------
- voice.js          (полная логика SPA + price priority + dynamic details)
- service-detail.html (чистый shell, контент подставляется динамически)
- *.html            (script v=40, id="spa-root")
- styles.css        (без изменений дизайна)
- assets/audio/*    (все 20 MP3 без изменений)
