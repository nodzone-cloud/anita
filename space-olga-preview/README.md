# S.P.A.C.E. 2.0 — рабочее пространство команды

Чистая программа без тестовых пользователей. Установка на компьютер, первый вход, файлы/фото/видео, общий и личные чаты.

## Первый вход (одноразовый)

| Поле   | Значение     |
|--------|--------------|
| Email  | `AN@An.com`  |
| Пароль | `Start123!`  |

После входа система **обязательно** попросит задать:
- постоянное имя
- постоянный email
- новый пароль

Ими вы будете входить всегда. Одноразовый `AN@An.com` больше не нужен.

То же для коллег: админ создаёт приглашение → коллега входит по временным данным → задаёт свои постоянные.

## Запуск на компьютере (без установщика)

Нужен [Node.js](https://nodejs.org) (LTS).

```bash
cd space
npm install
npm start
```

Откройте браузер: **http://localhost:3000**

Окно терминала должно оставаться открытым, пока вы работаете.

## Установка как программа с иконкой (Windows)

```bash
cd space
npm install
npm run pack
```

Готовый установщик появится в папке `dist\` (файл `.exe`).  
Его можно отправить клиенту: установка → ярлык на рабочем столе → запуск S.P.A.C.E..

Для разработки в окне Electron:

```bash
npm run electron
```

## Что внутри

- **Чистая база** — нет Марии, Олега и других фейков
- **Файлы / Фото / Видео** — общее хранилище, загрузка с компьютера
- **Общий чат** — групповой для всей команды
- **Личные чаты** — приватные переписки между двумя людьми
- **Задачи, школа, мероприятия, онбординг, материалы**
- **Админ** — приглашения, роли
- **Оффлайн** — уже загруженные на этот ПК файлы открываются без интернета; чат и синхронизация между домами — когда есть сеть

## Несколько домов / интернет

1. Один компьютер (или VPS) запускает S.P.A.C.E..
2. Открываете порт 3000 в роутере/файрволе (или деплой на Railway/Render).
3. Коллеги заходят по адресу `http://IP-или-домен:3000` и регистрируются / входят по приглашению.

Данные (файлы, сообщения) хранятся на том компьютере, где запущен сервер (`data/`).

## Смена одноразового входа

Удалите папку `data` и перезапустите — создастся чистая база снова с `AN@An.com` / `Start123!`.
